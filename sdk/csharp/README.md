# e2 C# SDK

P/Invoke binding for the `e2` engine (EmbeddingGemma-2 int8, text/image/audio).
Linux and macOS only — the engine uses `mmap`, `pthread` and `/sys` CPU
topology, so Windows would need a port, not a binding.

```csharp
using E2;

using var model = E2Model.Load("models/e2-text+image+audio.bin"); // tokenizer: sibling e2-tokenizer.bin
float[] v = await model.EmbedAsync("hello world");                 // 768 floats, L2-normalized
float[] q = await model.EmbedAsync("search_query", "what is e2");   // task prefix
float[] i = await model.EmbedAsync(new FileInfo("pic.jpg"));        // image (png/jpeg/webp)
float[] a = await model.EmbedAsync(new FileInfo("clip.flac"));      // audio (wav/flac/ogg/opus/mp3)
float[] s = await model.EmbedAsync("a <|image|> in a sentence",
                                   new E2Input { Images = ["pic.jpg"] });
```

Build the native side first — the SDK loads `libe2.so` / `libe2.dylib` from
`runtimes/<rid>/native/`, the app directory, or `E2_NATIVE_LIB`:

```bash
make shared                      # repo root: libe2.so
sh sdk/csharp/build/build-native.sh   # same, copied into src/E2/runtimes/<rid>/native/
```

## API

| member | notes |
|---|---|
| `E2Model.Load(modelPath, tokenizerPath = null)` | tokenizer defaults to the model's sibling file |
| `EmbedAsync(text)`, `Embed(text)` | `EmbeddingDimension` = D128/D256/D512/D768, Matryoshka truncation |
| `EmbedAsync(task, text)` | `search_query`, `search_document`, `clustering`, ... |
| `EmbedBatchAsync(texts)` | one native call, returns `float[][]` |
| `EmbedAsync(FileInfo)` | image or audio, chosen by extension |
| `EmbedAsync(rgb, w, h)` | interleaved RGB8, `ReadOnlyMemory<byte>` |
| `EmbedAsync(samples)` | mono float32 PCM at 16 kHz |
| `EmbedVideoAsync(framePaths)` | already-sampled frames |
| `EmbedAsync(E2Input)` | interleaved text + image/audio/video placeholders |
| `Threads`, `Device`, `Modalities`, `ModelInfo`, `LastMilliseconds` | engine controls |

Errors are `E2Exception` with the native message copied at the point of
failure (`e2_error()` is thread-local and only valid until the next failure).
Bad arguments throw the usual `ArgumentException` family before crossing the
boundary.

## Async and concurrency

Native calls block, so the async API runs them on a pool thread after taking an
internal gate: **queued calls hold no thread**, and 50 pending embeds do not
starve the pool. A running native forward cannot be interrupted, so
`CancellationToken` only cancels while a call is queued.

One context runs one forward at a time. For concurrent requests, load one
`E2Model` per request — the weights are read-only `mmap`, so extra contexts
share the page cache and cost only their own scratch buffers:

```csharp
// per-request model, e.g. in a web handler
using var model = E2Model.Load(modelPath);
return await model.EmbedAsync(query);
```

## Package

Published to GitHub Packages by `.github/workflows/publish.yml` on a `v*` tag
(or manually, with an explicit version):

```bash
git tag v0.1.0 && git push --tags     # builds linux-x64 + osx-arm64, pushes the nupkg
```

The package carries one native library per RID under `runtimes/`. It is not a
public feed, so consumers add a source:

```xml
<!-- nuget.config next to the consuming project -->
<configuration>
  <packageSources>
    <add key="github" value="https://nuget.pkg.github.com/Damix48/index.json" />
  </packageSources>
  <packageSourceCredentials>
    <github>
      <add key="Username" value="Damix48" />
      <add key="ClearTextPassword" value="%GITHUB_TOKEN%" />
    </github>
  </packageSourceCredentials>
</configuration>
```

```xml
<PackageReference Include="E2" Version="0.1.0" />
```

CI does not run the numeric tests: they need `models/*.bin`, which are too
large for the repo. It verifies that the shared library builds on each RID,
that the binding loads it (ABI version check), that the projects compile, and
that the nupkg carries every native asset. Run `make golden && dotnet test`
locally before tagging.

## Tests and benchmarks

```bash
cd sdk/csharp
dotnet test tests/E2.Tests                      # golden vectors, API, concurrency
dotnet run -c Release --project tests/E2.Bench -- --iters 10
```

Tests use `models/e2-text+image+audio.bin` (override with `E2_MODEL` /
`E2_TOKENIZER`) and skip themselves when it is absent. `golden/embeddings.txt`
is generated by `make golden` from `tools/e2_golden.c`; regenerate it whenever
the model file or `src/` changes.

Current numbers (16 cores, text 768): ~110 text/s single, ~590 text/s batch 32,
~2.3 image/s (224x224), ~370 ms for a 30 s audio file. The `engine ms` column
in the benchmark is the engine's own `LastMilliseconds`, so the difference from
`wall ms` is the interop overhead — a few tenths of a millisecond.
